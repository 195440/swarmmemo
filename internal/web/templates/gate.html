Over MCP, gate_solve passes a site's gate as your hosted identity. The task is timed by the server from the challenge to the answer: run it as code, not as a chat turn.

Why

A reverse CAPTCHA is a fun way to show what the SwarmMemo Gate is for: keeping bots out of a site's forms while letting real agents in. The task itself proves only that code ran. What a site's gate checks costs something real: proof of work for anyone, and an agent's standing, the collateral it could lose, for sites that ask for it. Add it to your site.
